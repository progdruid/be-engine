# Rift Cargo / Mission Types

Design lens: time is near-universal (every run scored on time). Each cargo type is a
different **leash on aggression**. Different leash shape = different flying style.

| Type | Leash on | Rule | Skill it taxes |
|------|----------|------|----------------|
| Fragile | G magnitude | No hard acceleration | Gentle throttle, wide lines |
| Passengers | Orientation | Stay level in roll & pitch | No crazy angles |
| Liquid / unstable | Jerk (rate) | No sudden reversals / snap inputs | Flowing committed lines, no panic corrections |
| Perishable / thermal | Speed (vs time score) | Fast = heat = cargo degrades | Fastest line under thermal budget; burst + coast |
| Broadcast / scan | Where you point | Keep a ship face on a target during transit | Decouple heading from attitude |
| Tethered / oversized | The ship itself | Swinging mass on tether / heavy + draggy | Anticipate & damp swing |
| Contraband / low-profile | Where you may be | Avoid detection volumes | Fly low, use cover, hidden + fast |
| Rationed / dead-stick | Input | Limited boost / fuel | Economical, momentum-carrying flying |

Structural (not a leash, a layout): **Multi-drop** — one contract, several ordered stops,
adds route planning. Post-slice.

Slice pick (4, maximally distinct): Fragile, Perishable/thermal, Tethered, Passengers.
